# 量化交易策略库

本目录包含4个经典的、广受认可的量化交易策略实现。

## 📚 策略概览

### 1️⃣ 双均线策略 (Dual Moving Average)
**文件**: `dual_ma_strategy.py`

**原理**:
- 最经典的技术分析策略
- 金叉（短期均线上穿长期均线）买入
- 死叉（短期均线下穿长期均线）卖出

**优势**:
- ✅ 简单易懂，容易实现
- ✅ 在趋势明显的市场表现良好
- ✅ 风险控制相对容易

**劣势**:
- ❌ 在震荡市场会产生频繁的假信号
- ❌ 滞后性较强

**适用场景**: 牛市、趋势明确的市场

**参考文献**:
- 最早可追溯到20世纪初的技术分析理论
- Brock, Lakonishok, and LeBaron (1992) "Simple Technical Trading Rules"

---

### 2️⃣ 动量策略 (Momentum Strategy)
**文件**: `momentum_strategy.py`

**原理**:
- "强者恒强" - 买入近期表现强劲的股票
- 基于价格动量、成交量、趋势强度等多维指标
- 使用风险调整动量（类似夏普比率）

**优势**:
- ✅ 在中国A股市场有显著效果
- ✅ 能够捕捉市场的中期趋势
- ✅ 结合多个维度的动量指标

**劣势**:
- ❌ 在市场反转时可能遭受较大损失
- ❌ 追涨策略心理压力较大

**适用场景**: 牛市、板块轮动行情

**参考文献**:
- Jegadeesh and Titman (1993) "Returns to Buying Winners and Selling Losers"
- 国内研究显示A股存在显著的1-12个月动量效应

---

### 3️⃣ 均值回归策略 (Mean Reversion)
**文件**: `mean_reversion_strategy.py`

**原理**:
- "物极必反" - 价格偏离均值后会回归
- 使用布林带识别超买超卖状态
- 结合RSI指标确认信号
- 设置止盈止损机制

**优势**:
- ✅ 在震荡市场表现优异
- ✅ 买入时机通常是价格低点
- ✅ 风险收益比较好

**劣势**:
- ❌ 在强趋势市场可能错过大行情
- ❌ "接飞刀"风险（下跌中买入可能继续下跌）

**适用场景**: 震荡市、横盘整理阶段

**参考文献**:
- Bollinger (1992) "Bollinger Bands"
- Gatev, Goetzmann, and Rouwenhorst (2006) "Pairs Trading"

---

### 4️⃣ Alpha101 多因子策略
**文件**: `alpha101_strategy.py`

**原理**:
- WorldQuant 发布的101个量化因子（2015）
- 本实现包含10个最经典和有效的因子
- 对因子进行截面标准化后等权组合
- 定期调仓维持因子组合

**包含的因子**:
1. Alpha#1: 波动率与价格的组合
2. Alpha#2: 成交量变化与价格变化的负相关
3. Alpha#6: 开盘价与成交量的负相关
4. Alpha#12: 成交量方向与价格变化的关系
5. Alpha#17: 价格趋势与成交量的综合
6. Alpha#19: 价格动量的反转信号
7. Alpha#21: 均值回归信号
8. Alpha#26: 成交量加权价格关系
9. Alpha#28: 价格成交量联动
10. Alpha#33: 开盘收盘价比率

**优势**:
- ✅ 经过大量数据验证的有效因子
- ✅ 多因子组合降低单一策略风险
- ✅ 全球市场广泛应用

**劣势**:
- ❌ 计算复杂度较高
- ❌ 需要较长的历史数据
- ❌ 因子有效性可能随时间衰减

**适用场景**: 各种市场环境，长期投资

**参考文献**:
- WorldQuant (2015) "101 Formulaic Alphas"
- Kakushadze (2016) "101 Formulaic Alphas (Corrected)"

## 🚀 使用方法

### 方法1: 单独使用某个策略

```python
from strategies.dual_ma_strategy import DualMAStrategy

# 创建策略实例
strategy = DualMAStrategy(short_window=5, long_window=20)

# 生成交易信号
signals = strategy.generate_daily_signals(data, date='2023-12-01', topk=30)

# 回测
results = strategy.backtest(
    data=data,
    start_date='2023-01-01',
    end_date='2023-12-31',
    initial_capital=1000000,
    topk=30
)

print(f"总收益率: {results['total_return']*100:.2f}%")
print(f"夏普比率: {results['sharpe_ratio']:.2f}")
```


**输出内容**:

- 🏆 策略综合排名

## 📊 策略评估指标

| 指标 | 说明 | 理想值 |
|------|------|--------|
| 总收益率 | 投资期内的总回报 | 越高越好 |
| 年化收益率 | 年化后的收益率 | >10% 优秀 |
| 夏普比率 | 风险调整后收益 | >1 良好，>2 优秀 |
| 最大回撤 | 最大的资产损失 | 越小越好，<-20% 可接受 |
| 年化波动率 | 收益率的标准差 | 越小越稳定 |
| 交易次数 | 总交易次数 | 过多或过少都不好 |

## 🎯 策略选择建议

### 市场环境 → 策略匹配

| 市场状态 | 推荐策略 | 理由 |
|----------|----------|------|
| 🐂 强势上涨（牛市） | 动量策略、双均线 | 跟随趋势，捕捉上涨 |
| 🐻 下跌趋势（熊市） | 现金为王 | 避免损失 |
| 📊 震荡整理 | 均值回归 | 高抛低吸 |
| 🔀 不确定/混合 | Alpha101多因子 | 分散风险，适应性强 |

### 风险偏好 → 策略匹配

| 风险偏好 | 推荐策略 | 特点 |
|----------|----------|------|
| 🛡️ 保守型 | 均值回归 + 止损 | 风险控制严格 |
| ⚖️ 平衡型 | Alpha101 | 风险收益平衡 |
| 🚀 激进型 | 动量策略 | 追求高收益 |

## 💡 最佳实践

### 1. 组合策略
不要只用单一策略，建议：
- 50% Alpha101（稳健）
- 30% 动量策略（进攻）
- 20% 均值回归（防守）

### 2. 参数优化
每个策略都有参数可以调整：
- 双均线：尝试不同的窗口组合（如5/10、10/20、20/60）
- 动量：调整回溯期和持有期
- 均值回归：调整布林带宽度和RSI阈值

### 3. 动态调整
根据市场环境动态调整策略权重：
```python
# 伪代码示例
if market_trend == '牛市':
    momentum_weight = 0.6
    mean_reversion_weight = 0.1
elif market_trend == '震荡':
    momentum_weight = 0.2
    mean_reversion_weight = 0.5
```

### 4. 风险控制
- ✅ 设置止损（建议 -5% 到 -10%）
- ✅ 设置止盈（建议 +15% 到 +20%）
- ✅ 控制单只股票仓位（<10%）
- ✅ 定期重新评估策略表现

## ⚠️ 风险提示

1. **历史表现不代表未来**: 回测结果好不代表未来一定能赚钱
2. **市场环境变化**: 策略的有效性会随市场环境变化
3. **过拟合风险**: 过度优化参数可能导致实盘表现差
4. **交易成本**: 实际交易有滑点、冲击成本等回测无法完全模拟的成本
5. **心理因素**: 实盘交易的心理压力远大于回测
